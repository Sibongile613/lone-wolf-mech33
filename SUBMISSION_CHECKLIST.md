# Submission Checklist

## Product

- [ ] Bot builds successfully with Docker
- [ ] Bot starts and reads the `mechfight/1` protocol
- [ ] Bot handles every observation without crashing
- [ ] Bot handles empty enemy, pickup, offer, and zone data
- [ ] Bot has a recognizable name in match results

## Evidence

- [ ] Demo replay or video link is included
- [ ] Benchmark instructions are reproducible
- [ ] At least 20 seeded matches are recorded
- [ ] Win placement, survival time, and kills are reported
- [ ] A final presentation explains strategy and limitations

## Repository quality

- [ ] README documents setup and execution
- [ ] Architecture is explained
- [ ] Unit tests cover critical pure decisions
- [ ] CI validates syntax and tests
- [ ] No secrets or credentials are committed
